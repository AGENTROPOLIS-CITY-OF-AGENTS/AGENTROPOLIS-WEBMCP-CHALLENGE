# PARALLAX Motion Contract

- Hero uses the cinematic PARALLAX environment video.
- The loop uses purposeful motion behind the protocol visualization.
- The live demo is real WebGL execution: agent movement, bounded mutations, see-again comparison, verification, receipt, and fail-closed denial.
- Governance corridor stages are request → identity → mandate → policy → authorization → execution → receipt.
- Only the active video may play; offscreen video pauses.
- Mobile and `prefers-reduced-motion` use static imagery and no autoplay motion.
- Timing sequences may choreograph presentation, but application/governance state remains authoritative.
