# PARALLAX Visual Canon

PARALLAX is a governed spatial control layer inside AGENTROPOLIS. The visual canon is obsidian/near-black, cyan primary signal, crimson secondary signal, black dimensional typography, translucent liquid glass, strong negative space, and a cinematic environment behind the interactive layer.

The wordmark face is always black/obsidian; cyan and red describe edge light only. Sections must share typography, spacing, border treatment, and environmental composition. Generic dashboard density, opaque hero panels, fake metrics, and decorative UI are rejected.
